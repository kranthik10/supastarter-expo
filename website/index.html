Frequently asked questions

Which platforms does it support?

iOS, Android and Web from a single Expo codebase. The starter exports cleanly for all three and runs in Expo Go for instant preview.

Do I need accounts for Stripe, OpenAI, etc.?

No. Everything runs in demo/offline mode out of the box. Add your keys later through environment variables when you're ready for production.

How do I connect a real backend?

Replace the demo provider in lib/auth-store.ts and point EXPO_PUBLIC_API_URL at your server. Screens only depend on the store interfaces.

Can my coding agent work with it?

Yes — AGENTS.md documents architecture, conventions and verification commands so Cursor, Claude Code, Codex and friends stay productive.

What about updates?

One-time purchase includes lifetime updates. Pull the latest changes any time; each category module is isolated so upgrades are low-risk.
